# Jayakanth Elumalai — Engineering Portfolio

Personal portfolio website hosted with GitHub Pages.

## Publish with GitHub Pages

1. Open the repository **Settings**.
2. Select **Pages** in the left navigation.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select branch **main** and folder **/(root)**, then save.
5. Wait for the Pages deployment to finish.

The expected website address is: https://jayakanthelumalai1.github.io/

## Update the website

Edit `index.html` in the repository. The page is a responsive, single-file HTML/CSS site and does not require a build step.

## Content

The portfolio includes the profile, education, Samsung experience, technical skills, selected projects and contact details supplied for the portfolio draft.
